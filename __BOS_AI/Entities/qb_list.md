# qb_list — QuickBooks list mirror (customer / item / class)

**ECK entity type** `qb_list` ("QuickBooks List Entry"), **3 bundles:** `customer`, `item`, `class`.
Base fields: `title` (relabelled **QuickBooks Full Name**), `status` (relabelled **Active in
QuickBooks**), `created`, `changed`; no `uid`. `standalone_url` → `/qb_list/{id}`. Created 2026-11-15
for [`bos_quickbooks`](../Modules/bos_quickbooks.md); config in `config/sync` (81 files, list in
`web/scripts/bos_quickbooks_config_files.txt`, generated by `bos_quickbooks_config_gen.php`).

## Ownership — the one rule

**QuickBooks owns every field except three.** The Web Connector sync overwrites title, status and all
`field_*` below on every run; the office changes them in QuickBooks, never here. The three BOS-owned
fields live on `customer` only: `field_bos_client`, `field_match_status`, `field_match_note`. The form
displays expose exactly those (customer) or nothing (item, class); `bos_quickbooks_form_alter()`
shows the QuickBooks record read-only above them.

## Lifecycle

- **Created / updated** only by `QbListMirror::upsert()` during a Web Connector session; written only
  when something QuickBooks owns changed.
- **Missing** set by `markMissing()` once that list's query has completed in a run; cleared by the
  next sync that returns the record.
- **Never deleted** by code (BOS rule 4). No `delete` permission below `site_admin`.
- `profile.customer_profile.field_qb_list_id` is a **derived copy** of the link, maintained by the
  presave hook, disabled on the profile form. Code that needs "the QuickBooks customer for this
  client" may read either; the `qb_list` row is authoritative.

## Access

`view quickbooks lists` (module) + ECK `view any qb_list entities` (+ per bundle) +
`edit any qb_list entities of bundle customer` + `access qb_list entity listing` →
`administration`, `site_assistant`, `site_admin`. `administer quickbooks integration` → `site_admin`.
No `teammates`, `supervisor`, `client` access. Views `qb_customers` / `qb_items` / `qb_classes` use
`perm: view quickbooks lists`.

## Views

`qb_customers`: page_1 `/admin/office/quickbooks/customers` (all; exposed name / last name / company /
active / match status / missing), page_2 `/admin/office/quickbooks/review` (active + present +
unmatched/ambiguous/duplicate). `qb_items` `/admin/office/quickbooks/items`. `qb_classes`
`/admin/office/quickbooks/classes`. All `perm`-gated, Views-UI editable; `⚠ Missing` column.
